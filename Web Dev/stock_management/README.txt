GESTÃO DE INVENTÁRIOS

Os sistemas de gestão de inventário requerem uma aplicação web com uma interação com um servidor de base de
dados para gerir os níveis de stock, processamento de encomendas, e dados de compras. A aplicação web precisa de
interagir com o servidor de base de dados para armazenar e recuperar informação de inventário, gerir níveis de stock,
e acompanhar o cumprimento de encomendas.
